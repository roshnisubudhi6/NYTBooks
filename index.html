Bring your NYT key and we'll print this week's issue

The Books API is free, but every request needs a personal key.

  1. Create a free account at developer.nytimes.com and sign in.
  2. Open Apps → New App, give it a name, turn on Books API, and save.
  3. Copy the app's API key and paste it here.

Your key stays in this browser's local storage and is only sent to api.nytimes.com.
